# Vulcan: Instance-specialized, Verifiable Systems Heuristics Through LLM-driven Search

This repo contains the code to reproduce the results of the case studies in [our paper](https://arxiv.org/pdf/2512.25065). Please checkout to the relevant branch and follow instructions in that branch's README:
* Single-region Spot VM scheduling: `cbl-artifact`
* Multi-region Spot VM scheduling: `cbl-multi-artifact`
* Caching policies: `caching-artifact`
